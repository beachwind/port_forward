# Command Manager

왼쪽 메뉴에서 로컬 CMD/PowerShell과 원격 서버 CLI 로그인을 관리하는 Python 유틸리티입니다.

## 실행

```powershell
py -m pip install -r requirements.txt
py command_manager.py
```

## 기능

- 왼쪽 메뉴에서 로컬 CMD, PowerShell 실행
- `Command 설정` 화면에서 command 실행 파일 등록, 수정, 삭제
- `Editor 설정` 화면에서 editor 실행 파일 등록, 수정, 삭제
- 홈 화면의 `Command 실행 파일` 콤보박스에서 실행 파일 선택
- 원격 서버 그리드 행 더블클릭 시 선택한 command 실행 파일로 서버 CLI 실행
- 기본 command로 PowerShell, Cygwin, PuTTY 자동 등록
- 원격 서버 프로필 추가, 수정, 삭제
- 로그인 창에서 `계정 정보 저장` 선택 시 Windows DPAPI로 암호화 저장
- 저장된 프로필로 새 콘솔 창을 열고 SSH 자동 로그인
- `파일 전송` 버튼으로 로컬/원격 분할 탐색기 실행
- 로컬/원격 분할 파일 탐색기에서 단일/다중 선택 드래그 앤 드롭 업로드/다운로드
- 파일 전송 상태 표시와 진행률 Progress Bar
- 로컬/원격 탐색기에서 파일 보기, 로그 실시간 보기, ANSI 색상 로그 보기, 클립보드 보기, 새 폴더/빈 파일 생성, 파일명 변경, 선택 항목 삭제, 현재 경로 터미널 열기
- 로컬/원격 탐색기 그리드에 파일/폴더 수정 날짜 표시
- 원격 탐색기에서 `scrot` 기반 스크린샷 캡처 후 로컬 PNG 저장/열기
- 로컬/원격 파일 탐색기 즐겨찾기 경로 등록과 콤보박스 이동

저장 파일은 `%APPDATA%\CommandManager\profiles.json`에 생성됩니다. 암호는 현재 Windows 사용자 계정에서만 복호화할 수 있습니다.

파일 전송은 선택한 서버 프로필의 로그인 정보로 별도 SFTP 연결을 열어 처리합니다. `파일 전송` 버튼을 누르면 왼쪽에는 로컬 파일 탐색기, 오른쪽에는 원격 서버 파일 탐색기가 표시됩니다. 폴더는 더블클릭으로 이동하고, 파일 항목을 하나 이상 선택한 뒤 반대쪽 목록으로 드래그하면 업로드 또는 다운로드가 실행됩니다. 반대쪽 폴더 위에 드롭하면 해당 폴더 안으로 전송되고, 같은 탐색기의 폴더 위에 드롭하면 파일이 그 폴더로 이동됩니다. 하단 상태 표시 옆의 Progress Bar는 전체 전송 바이트 기준 진행률을 표시합니다. 경로 이동 TextBox에서는 Enter 키로 이동할 수 있습니다. 로컬/원격 패널의 버튼은 아이콘으로 표시되며 마우스를 올리면 ToolTip으로 버튼명이 표시됩니다. `등록` 버튼은 현재 경로를 즐겨찾기 콤보박스에 저장하고, 콤보박스에서 경로를 선택하면 해당 탐색기가 그 경로로 이동합니다. 각 패널의 `파일 보기`, `로그 보기`, `로그 보기(색상)`, `클립보드 보기`, `새 폴더`, `빈 파일`, `파일명 변경`, `삭제`, `터미널` 버튼으로 현재 경로 관리와 터미널 실행을 할 수 있고, 그리드 우클릭 메뉴에서도 같은 파일 작업을 실행할 수 있습니다. 우클릭 `파일 보기` 서브메뉴의 `(default)`는 내장 텍스트 뷰어를 사용하고, `Editor 설정`에 등록한 editor 이름을 선택하면 해당 실행 파일로 파일을 엽니다. 원격 파일은 임시 폴더로 내려받은 뒤 editor로 엽니다. 원격 클립보드 보기는 `xclip`, `xsel`, `wl-paste` 순서로 원격 명령을 시도합니다. 원격 로그 보기는 `tail -n 200 -F`로 실시간 표시하며, 색상 로그 보기는 ANSI 색상 코드를 Tk Text 태그로 변환해 표시합니다. 원격 패널의 `스크린샷` 버튼은 `DISPLAY=:0 scrot -o /dev/stdout`을 실행해 PNG를 로컬에 저장하고 기본 이미지 뷰어로 엽니다. 로컬 패널의 `Explorer` 버튼은 현재 로컬 경로를 Windows 탐색기로 엽니다.

Command 설정은 이름, 실행 파일 경로, 실행 인자, 작업 폴더를 저장합니다. 저장된 command는 홈 화면 상단 콤보박스에 표시됩니다. 콤보박스에서 command를 선택한 뒤 원격 서버 그리드의 서버 행을 더블클릭하면 선택한 command 실행 파일을 통해 서버 CLI가 실행됩니다. command 선택이 없을 때 서버 행을 더블클릭하면 기존 기본 CLI로 로그인합니다. 파일 전송 탐색기의 `터미널` 버튼도 같은 command 선택값을 사용합니다.

기본 command는 PowerShell, `C:\Util\cygwin\cygwin64\Cygwin.bat`, `cygwin_mintty`, `cygwin_bash`, `C:\Util\putty\putty.exe`입니다. PuTTY는 `-ssh`, `-l`, `-P`, `-pw` 인자로 직접 자동 로그인합니다. Cygwin은 `Cygwin.bat`, `mintty.exe`, `bash.exe` 중 어느 항목을 선택해도 Cygwin bash에서 `ssh_cli.py`를 실행합니다.
